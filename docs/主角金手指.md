我要写一本 吞噬星空 同人小说 我设计的主角是这样的 一道金光射到 地球上的一个深埋地下的尸体上， 尸体开始吸收周边能量，以及周边生物的能量，尸体生死白肉，这就是主角，然后主角活了之后，脑海里有3个玻璃珠一样的金色小球， 好像是灵魂金球， 主角的金手指就是 这些金色小球可以融合 生命残骸或者资源物质 变成他的完美分身， 主要原理是 金色小球 解析遗传物质，吞噬，融合，固化，可以获取该遗传物质原主人的一切记忆，以及修炼过程，修炼所得，但是由于融合，固化，会继承原主记忆，导致主角出现精神分裂问题，为了防止这种问题，需要把融合吞噬的记忆存储起来，这样就意味着 原主的修炼所得也会封存起来，主角随着一点点解封，通过对融合修炼记忆进行拆解，理解成自己的， 只有这样才会防止自己出现精神分裂。 另外每个分身由于都是金色小球制造的分身，通过意识灵魂任然保留了 吞噬，解析，的能力，但是不能 固化为分身了。 主角的金手指就是4个金色小球制造成的4个分身， 本质上我的设计是 这4个小球是 浑源空间中的 特殊生命的4滴血液， 这个生命的特点就是 吞噬一切物质，可以吞噬无限浑源空间中的一切东西，由于无限吞噬，这种生命就是混乱的代表，混乱的原因就是吞噬的太多，已经精神分裂了， 浑源空间的 浑源道主 获取了4滴这个生命的血液，斩断这4滴血液于 这个特殊生命的一切，但是血液天生的 吞噬本能仍然存在， 浑源道主把4滴处理后的血液投给了主角， 第一滴跟主角骨骼融合，形成一个身体，还有3滴， 每个行成的身体 任然 保留吞噬的欲望 ，吞噬，解析的本能 主角用这种能力 一步步崛起， 然后掌控这个吞噬的能力，做到意志于这4滴完美融合 最终成为浑源生命，反向吞噬掉了 原来混乱的特殊生命。 这是我的基本大框架结构 你认为这种设计怎样？ 有没有什么漏洞，另外，你给这个能力进行总结分析，甚至完善。
